# 삼스 864 (sams864)

3BLD 3-style 공식 864개를 한 화면에서 익히고 진척도를 관리하는 단일 HTML 파일 웹앱입니다.
버퍼는 코너 UFR / 엣지 UF 기준입니다.

## 864개의 구성

| 분류 | 개수 |
|---|---:|
| 코너 (UFR 버퍼) | 378 |
| 엣지 (UF 버퍼) | 440 |
| 패리티 | 21 |
| 엣지 플립 (UF + 다른 엣지 1개) | 11 |
| 코너 트위스트 (UFR 포함 2점) | 14 |
| **합계** | **864** |

## 기능

**공식표 — 두 가지 보기**
- 목록: 첫 글자별 카드 그리드
- 표: 스프레드시트와 같은 가로세로 행렬 (**열 = 첫 글자**, 행 = 끝 글자). 첫 글자 열과 상단 행이 고정되어 스크롤해도 기준이 보임

**진척도**
- 공식을 클릭할 때마다 미학습 → 완료(초록) → 애매(노랑) → 안 외워짐(빨강) 순환
- 열/줄 단위 일괄 완료 처리
- 상단에 코너+엣지 818개 기준 진행 바, 패리티·플립·트위스트는 별도 집계
- 필터: 전체 / 완료 숨기기 / 복습만

**역공식 표시 · 숨김**
- 숨김으로 두면 앞선 열에서 이미 익힌 조합의 역방향이 사라져, 열마다 20 → 19 → 18개… 로 줄어드는 삼각형 구조가 됩니다
- 단 **암기용 공식**(커뮤테이터가 아닌 통짜 공식)은 뒤집어서 유도할 수 없으므로 숨김 상태에서도 계속 표시됩니다
- 숨김 상태에서 한 방향을 완료 처리하면 짝이 되는 역방향도 함께 처리됩니다

**레터링 스킴**
- 큐브 전개도에서 글자를 직접 수정. 수정 즉시 모든 공식표의 페어 이름이 바뀜
- Speffz 프리셋 한 번에 전환 (버퍼 5칸 — 엣지 C·I, 코너 C·J·M — 포함)
- 진척도는 위치 기준으로 저장되므로 스킴을 바꿔도 유지됨
- 코너·엣지 각각 나열 순서 변경 가능

**보조 공식**
- 패리티 21개, UF 엣지 플립 11케이스, UFR 코너 트위스트 14케이스
- 플립·트위스트는 케이스마다 대안 공식을 함께 수록

## 실행

```bash
git clone <이 저장소 주소>
cd sams864
open index.html          # macOS. 리눅스는 xdg-open, 윈도우는 start
```

### GitHub Pages로 배포

Settings → Pages → Source를 `main` 브랜치 루트로 지정하면
`https://<사용자명>.github.io/sams864/` 에서 열립니다.

## 진척도 저장

브라우저 `localStorage`에 저장됩니다. 기기나 브라우저가 바뀌면 따라가지 않으므로,
설정 탭의 **진행상황 파일로 저장 / 파일 불러오기**로 옮기세요.
브라우저 데이터를 지우면 진척도도 사라집니다.

## 데이터 출처와 검증

- **코너 378 · 엣지 440**: 사용 중인 개인 3-style 공식집(Google 스프레드시트)에서 추출. 엣지 시트에 한 방향만 적혀 있던 211개는 반대 방향 공식의 커뮤테이터 순서를 교환해 유도했고, 표에 `역` 배지로 구분해 두었습니다.
- **패리티 21**: 개인 노션 정리본.
- **엣지 플립 11 · 코너 트위스트 14**: [BLDDB](https://blddb.net/)의 공개 데이터베이스에서 추출 (케이스별 상위 순위 공식).
- **검증**: 코너·엣지 818개 전부를 큐브 시뮬레이터에 대입해, 버퍼→첫 글자→끝 글자 3-사이클이 정확히 일어나고 다른 조각은 전혀 움직이지 않는지 스티커 단위로 전수 확인했습니다. 오류 0건.
- 표기는 `셋업 : [A, B]` 형식으로 통일했습니다.
